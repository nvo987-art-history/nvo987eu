# NVO987.eu – Agenda Culturel (Paris Open Data)

This repository contains the source code of:

**https://nvo987.eu**

NVO987.eu is an independent, lightweight web interface presenting selected
cultural events in Paris using data made available through the official
Paris Open Data platform.

The website is not an official service of the City of Paris.

The official source remains the authoritative reference for the underlying
event information.

---

## Purpose of the project

The purpose of this project is to provide a simple public interface for
discovering cultural events in Paris.

The website retrieves and presents selected event information originating
from the following official Open Data dataset:

**"Que faire à Paris ? – Évènements et activités"**

The presentation, interface, search functionality and website design are
independently developed by NVO987.

## GitHub Pages deployment

To deploy the website using GitHub Pages:

1. Open **Settings → Pages**
2. Select the `main` branch
3. Select the `/ (root)` folder
4. Save the configuration

GitHub Pages will then publish the website.
